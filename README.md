# SESI Voleibol Bauru (Vite + React + Tailwind + Three.js)

## Rodar no VS Code
1. Abra a pasta no VS Code e o terminal integrado (Ctrl+`).
2. `npm install`
3. `npm run dev` e abra o endereço mostrado (normalmente http://localhost:5173).
Build de produção: `npm run build`.

Para criar do zero em vez de usar esta pasta: `npm create vite@latest sesi-voleibol -- --template react`,
depois `npm i three` e `npm i -D tailwindcss@3.4.17 postcss autoprefixer` e copie `src/`, `tailwind.config.js`, `postcss.config.js`.

## Extensões úteis
Tailwind CSS IntelliSense, ES7+ React/Redux/React-Native snippets, ESLint, Prettier.

## Conteúdo
Edite `src/data.js`: elenco, jogos e unidades são exemplos. Confira títulos, números e endereços antes de publicar.
